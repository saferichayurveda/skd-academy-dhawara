# School Photo & Video Gallery

Upload approved school photos and videos to this folder using the GitHub account or collaborators authorised to edit this repository.

Supported formats: JPG, JPEG, PNG, WEBP, GIF, AVIF, MP4, WEBM, MOV.

Keep individual files small (ideally under 20 MB; GitHub browser uploads have size limits). Files in this public repository will be visible to everyone on the school website.
