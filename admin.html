फोटो एवं वीडियो गैलरी व्यवस्थापन

फोटो / वीडियो जोड़ें

मुफ्त GitHub तरीके में मीडिया आपकी अधिकृत GitHub repository से जोड़ा जाएगा। अपलोड करने के लिए उसी GitHub खाते में साइन इन होना जरूरी है जिसके पास इस repository में बदलाव करने की अनुमति है।

ध्यान दें: इस repository की फाइलें सार्वजनिक हैं। यहाँ जो फोटो/वीडियो जोड़े जाएँगे, वे वेबसाइट पर सभी लोग देख सकेंगे। केवल विद्यालय द्वारा प्रकाशित करने योग्य सामग्री जोड़ें।

GitHub में फोटो / वीडियो जोड़ें ↗

मोबाइल से कैसे जोड़ें?

  1. ऊपर दिए गए बटन को दबाएँ और GitHub में साइन इन करें।
  2. फोन की Gallery से फोटो या वीडियो चुनें।
  3. नीचे जाकर Commit changes दबाएँ।
  4. Cloudflare वेबसाइट के अपडेट होने के लिए कुछ मिनट प्रतीक्षा करें।

बेहतर परिणाम के लिए छोटी फाइलें रखें (लगभग 20 MB से कम)। समर्थित प्रकार: JPG, PNG, WEBP, GIF, AVIF, MP4, WEBM, MOV।
